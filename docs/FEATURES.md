**이 문서가 GitHub Issue의 원본입니다.** Issue를 만들 때 해당 기능 섹션을 그대로 옮겨 붙입니다.

| 찾는 것 | 문서 |
|---|---|
| 기획 · 역할 · 2일 일정 · 미확정 사항 | [PLANNING.md](PLANNING.md) |
| API 요청·응답 계약 | [api.md](api.md) |
| 브랜치 · 커밋 · PR · Secret 규칙 | [../CONTRIBUTING.md](../CONTRIBUTING.md) |

> ⚠️ **진행 상태의 기준은 GitHub Issue입니다.** 이 문서의 `상태` 칸은 참고용이고, 최신이 아닐 수 있습니다.
> 어느 쪽이 맞는지 헷갈리면 **Issue를 믿으세요.**

## 읽는 방법

**기능 ID** — `F1` ~ `F7`. 기능 하나 = Issue 하나입니다.

**상태** — `미착수` / `진행중` / `완료`

**우선순위**

| | 뜻 |
|---|---|
| **P0** | 이게 늦으면 **다른 담당자가 손을 놓습니다.** 먼저 끝내야 합니다 |
| **P1** | MVP 필수지만, 늦어도 다른 사람은 Mock으로 계속 일할 수 있습니다 |

**Issue로 옮기는 순서**

1. `.github/ISSUE_TEMPLATE/feature.md` 로 Issue 생성
2. 제목은 `[Feat] F3 일정 정제 — 공통 스키마 정규화` 형태
3. 아래 해당 섹션의 **목표 / 구현 범위 / 완료 조건**을 그대로 붙여넣기
4. Milestone(`Day 1` / `Day 2`)과 담당자 지정
5. 발급된 Issue 번호를 이 문서의 `Issue` 칸에 적기

## 의존성

```text
[직렬 — 깨지면 뒤가 전부 막힌다]

── 브라우저 ─────────────────────────────────────────────
  F1  LMS Calendar fetch
   → F2  HTML 파싱 / raw 일정 JSON 생성
        │
        ▼  ========== [ Backend API 경계 ] ==========
── 서버 ─────────────────────────────────────────────────
  F3  일정 정제 / 공통 스키마 변환          ★ 최우선 병목
   → F4  Supabase 저장·조회 / 팀 기능
   → F7  부담도·여유도 계산                 ↑ F4 응답 형태에 의존
        │
        ▼
── 브라우저 (화면) ───────────────────────────────────────
  F6  Heatmap 표시                          F7 결과를 조회해 렌더링

[병렬 — 위와 무관하게 즉시 시작 가능]
  F5  로그인 · 팀 화면               ← Mock으로 선행
  F6  Heatmap 화면 골격              ← Mock으로 선행, 실제 연결만 F7 대기
  F4의 팀 기능(생성/초대코드/참가)    ← F3 없이도 착수 가능 (저장 부분만 F3 대기)
```

**병목 2개 — Day 1 오전에 먼저 합의해야 합니다**

1. **F3의 공통 스키마** — F1·F2·F4·F7이 전부 이걸 기준으로 작업합니다.
2. **F4의 팀 조회 응답 형태** — F6·F7의 전제입니다. 정해지는 즉시 [api.md](api.md)에 한 줄 추가.

## 완료 조건에 넣지 않은 것

**아직 확정되지 않았기 때문입니다.** 확정되면 해당 기능의 완료 조건에 추가하세요.
확정 현황은 [PLANNING §13 미확정 사항](PLANNING.md#13-미확정-사항)이 기준입니다.

| 미확정 | 영향받는 기능 |
|---|---|
| API 엔드포인트 경로 · 필드명 · 에러 `code` (현재 [api.md](api.md) 등록 0개) | F4 · F5 · F6 · F7 |
| DB 테이블 · 컬럼 이름 | F4 |
| 정제 후 공통 스키마 필드 | F1 · F2 · F3 · F4 · F7 |
| 부담도 · 여유도 **계산식과 수치 기준** | F7 |
| Frontend 프레임워크 | F5 · F6 |
| 브라우저 실행 모듈의 **디렉터리 위치** *(실행 위치 자체는 확정)* | F1 · F2 |
| 부담도를 화면에서 보여주는 방식 | F6 |

> 위 항목은 **완료 조건으로 쓸 수 없습니다.** "필드명이 맞는지"를 완료 조건에 넣으면, 필드명이 바뀔 때마다 Issue가 다시 열립니다.
